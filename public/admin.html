Connect Square

Online orders and payments go straight to the restaurant’s Square POS.

Mode
Square keys
Starts with sq0idp- (live) or sandbox-sq0idb- (test).
Saved
Secret. Stored only on Foodol’s server and never shown to guests.
Optional
Leave blank to use the restaurant’s first active location.
What Foodol uses
  • Reads the menu and prices
  • Calculates tax on each order
  • Creates pickup orders placed through Foodol
  • Charges the guest’s card for those orders
  • Doesn’t read past sales, reports or customers
  • Doesn’t change menus, prices or settings
  • Doesn’t touch payouts or bank details
Where do I find these?
  1. Go to developer.squareup.com and open the app.
  2. Choose Production (live) or Sandbox (test) at the top.
  3. Credentials shows the Application ID and Access token.
  4. Locations shows the Location ID.

Connect Clover

Online orders go straight to the restaurant’s Clover POS, and payments land in their Clover account.

Mode
Clover account
13 characters, in the dashboard address bar: …/merchants/XXXXXXXXXXXXX/…
Saved
Setup → API Tokens. Tick only Inventory: Read and Orders: Write.
Online payments Needed for guests to pay in Foodol
Saved
Setup → Ecommerce → Ecommerce API Tokens, type “Hosted iFrame + API”. Safe to show in the browser.
Saved
Same page. Secret: stored only on Foodol’s server.
What Foodol can do with these keys
  • Read the menu: item names, prices, categories
  • Add new pickup orders placed through Foodol
  • Charge the guest’s card for those orders. Money goes straight to the restaurant’s Clover account
  • Can’t see past sales, reports or other orders
  • Can’t see customers, staff or timecards
  • Can’t touch payouts, bank details or refunds
  • Can’t change the menu, prices or settings
The restaurant can cut Foodol off anytime by deleting the token in their Clover dashboard.
Where do I find these?
  1. Log in at clover.com on a computer.
  2. Copy the Merchant ID from the address bar.
  3. Account & Setup → API Tokens → Create new token. Name it “Foodol” and tick Inventory (Read) and Orders (Write).
  4. Account & Setup → Ecommerce → Ecommerce API Tokens → Create new token, type “Hosted iFrame + API”. Clover asks for two-step verification first.
